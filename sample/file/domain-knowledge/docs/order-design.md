# 受注機能 設計書

## 1. 用語
| 用語 | 説明 |
| --- | --- |
| 顧客区分 | 1: 個人、2: 法人、3: 官公庁 |
| 与信枠 | 顧客ごとに設定する未入金受注の上限額 |

## 2. 受注登録
- 明細が1件以上あること。
- 会員ランクに応じて割引する（GOLD 5%、SILVER 2%）。
- 未入金受注の合計と今回の受注合計の和が与信枠を超える場合は登録不可。
- 受注合計が **50万円以上** の場合は承認待ちとする。

## 3. 高額受注の承認
1. 営業課長が管理画面で承認待ちの受注を確認し、承認または却下する。
2. 承認されると、翌朝 6:00 の引当バッチで在庫を引き当てる。
3. 却下された受注はキャンセルとする。

## 4. キャンセル
- 出荷準備に入る前（受付・引当済）までキャンセルできる。

## 5. 未入金受注の自動キャンセル
- 個人顧客の未入金受注は、受注から72時間を超えたら自動キャンセルする。
