| ID | ルール名 | 内容 | 理由 |
| --- | --- | --- | --- |
| R-01 | 引当可能数 | 引当可能数 = 実在庫 − 引当済数 − 安全在庫 | |
| R-02 | 在庫不足の判定 | 明細ごとに、引き当てられる数が明細の数量未満なら在庫不足として引当できない（等しい場合は引当できる）。引当できた明細は数量分だけ引当済数を増やす | |
| R-03 | GOLD 会員の安全在庫までの引当 | 会員ランクが GOLD の顧客の受注は、安全在庫を差し引かず「実在庫 − 引当済数」まで引き当ててよい。GOLD 以外は引当可能数（R-01）まで | |
| R-04 | 引当解除 | 引当を解除するときは、明細ごとに数量分だけ引当済数を減らす | |
