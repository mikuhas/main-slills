# 在庫ドメイン知識

SKU ごとの在庫数量と、受注に対する在庫の引当・引当解除を扱う。

## 使い方
次の場面では、**このファイルと同じディレクトリにある該当ファイルを読んでから回答する**。読まずに推測で答えない。

| 読むファイル | 読む場面 |
| --- | --- |
| `glossary.md` | 用語・コード値の意味を答えるとき |
| `rules.md` | 計算・制約・状態遷移の条件を答えるとき |

この領域に無い用語・ルール（顧客・会員ランク・引当）を聞かれたら、`domain-common` の skill を読む。
