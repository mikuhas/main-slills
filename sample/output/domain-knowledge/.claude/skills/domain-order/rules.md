| ID | ルール名 | 内容 | 理由 |
| --- | --- | --- | --- |
| R-01 | 明細の必須 | 明細が1件以上ない受注は登録できない | |
| R-02 | 会員ランク割引 | 会員ランクが GOLD なら 5%、SILVER なら 2% を明細合計から割り引く | |
| R-03 | 割引の対象外と端数処理 | 会員ランクが NORMAL の場合は割り引かない。割引後の金額は円未満を切り捨てて受注合計とする | |
| R-04 | 与信枠による登録不可 | 顧客の未入金受注の合計と今回の受注合計の和が与信枠を超える場合は登録できない（等しい場合は登録できる） | |
| R-05 | 与信枠判定に使う金額 | R-04 の「今回の受注合計」は会員ランク割引後の金額を使う | |
| R-06 | 高額受注の承認 | 受注合計が 100万円以上の受注は承認待ちで登録する。100万円未満の受注は承認不要として登録する | |
| R-07 | 承認不要の受注の即時引当 | 承認不要の受注は、登録時に在庫を引き当て、状態を引当済にする。承認待ちの受注は登録時に引き当てず、状態は受付のまま | |
| R-08 | キャンセルできる状態 | 出荷準備に入る前（受付・引当済）の受注だけキャンセルできる。出荷準備・出荷済の受注はキャンセルできない | |
| R-09 | キャンセル時の処理 | 受注をキャンセルすると状態をキャンセルにする。引当済の受注は引き当てた在庫を解除する | |
| R-10 | 個人顧客の未入金受注の自動キャンセル | 個人顧客の未入金受注は、受注から 72時間を超えたら自動キャンセルする | |
| R-11 | 法人の未入金受注は自動キャンセルしない | 法人顧客の未入金受注は、経過時間にかかわらず自動キャンセルしない | 法人は請求書払いのため |
