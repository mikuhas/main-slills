# 共通ドメイン知識

受注と在庫の複数領域で共通して使う顧客・会員ランク・引当の用語を扱う。

## 使い方
次の場面では、**このファイルと同じディレクトリにある該当ファイルを読んでから回答する**。読まずに推測で答えない。

| 読むファイル | 読む場面 |
| --- | --- |
| `glossary.md` | 用語・コード値の意味を答えるとき |

領域ごとの用語・ルールを聞かれたら、`domain-order`（受注）または `domain-inventory`（在庫）の skill を読む。
